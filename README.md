# Data Engineering and Analytics Portfolio

A collection of practical projects focused on data engineering, SQL, and data analytics.

## Projects

### 01. Retail Data Warehouse

**Status:** Completed

A SQL Server data warehouse built using the Medallion Architecture.

**Key components:**

- **Bronze Layer:** Raw data ingestion.
- **Silver Layer:** Data cleaning and transformation.
- **Gold Layer:** Analytical data modeling.
- SQL stored procedures for data loading.
- Data quality checks and validation.
- Documentation covering requirements, data catalog, and naming conventions.

**Technologies:** SQL Server, T-SQL.

**Project structure:**

- `data/` — CRM and ERP source datasets.
- `docs/` — Project documentation.
- `sql/` — Database initialization, layer definitions, and loading procedures.
- `tests/` — Silver and Gold layer validation scripts.
