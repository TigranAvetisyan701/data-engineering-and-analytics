# Data Engineering and Analytics Portfolio

A collection of practical projects focused on data engineering, SQL, data warehousing, and data analytics.

## Projects

### 01. Retail Data Warehouse

**Status:** Completed

A SQL Server data warehouse built using the Medallion Architecture.

**Key components:**
- Bronze, Silver, and Gold data layers.
- ETL processes using SQL stored procedures.
- Data cleaning and transformation.
- Analytical data modeling.
- Data quality checks and validation.
- Technical documentation.

**Technologies:** SQL Server, T-SQL, ETL, Data Warehousing, Medallion Architecture.

### 02. Retail Exploratory Data Analysis

**Status:** Completed

An exploratory data analysis project using SQL Server and T-SQL to investigate retail business data and identify meaningful patterns.

**Key components:**
- Database and dimension exploration.
- Date and customer age analysis.
- Business metrics calculation.
- Magnitude analysis across business dimensions.
- Revenue analysis by products, categories, and customers.
- Ranking analysis of products and customers.

**Technologies:** SQL Server, T-SQL, Exploratory Data Analysis, SQL Aggregations, Window Functions.

### 03. Retail Advanced Data Analytics

**Status:** Completed

An advanced SQL analytics project focused on evaluating retail business performance and generating customer-level analytical reports.

**Key components:**
- Change over time analysis.
- Cumulative sales analysis.
- Product performance analysis.
- Part-to-whole analysis.
- Product and customer segmentation.
- Customer analytical report using a SQL view.

**Technologies:** SQL Server, T-SQL, CTEs, Window Functions, SQL Views, Data Segmentation.
